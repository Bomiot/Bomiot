#### APP 操作教程


#### 第一次运行app

![image-01](/media/img/oq5qxw.png){ loading=lazy style="max-width: 50%" }
-
- 语言默认为英文，可通过点击文按钮-中文简体，选择语言为中文简体

#### 设置服务器
- 点击设置下的服务器按钮,配置好服务器地址后，点击登入按钮，输入用户名密码后点击提交即可登录

![image-15](/media/img/server.png){ loading=lazy style="max-width: 50%" }

- 如果您是管理员登录，则不用输入OPENID，直接输入部署好的请求地址，注意末尾没有"/"，格式为"http://ip:8008"
- 如果您是普通用户登录，请向您的管理员索要openid，以及用户名和验证码

#### 第一部分 登入

![image-03](/media/img/od4oid.png){ loading=lazy style="max-width: 50%" }

#### 第二部分 收货管理

- 点击收货管理下的到货通知书，即下图所展示的内容

- 可配合web端上的扫描到货通知书的二维码，来查看这张到货通知书的详情

![image-04](/media/img/ic4fqc.png){ loading=lazy style="max-width: 50%" }

- 进行上架操作，或者扫到货通知书的二维码，出现以下信息，如果扫描的到货通知书二维码还不能上架，则扫出来的数据则是空的

![image-05](/media/img/by07be.png){ loading=lazy style="max-width: 50%" }

- 点击要上架的到货通知书，或者扫描要上架的货品码，确认要上架的库位名称和上架的数量，点击确认按钮即可，这次上架就完成了，如果还想再次上架或者操作其他到货通知书，请扫描相应的到货通知书。

![image-06](/media/img/xnyk4e.png){ loading=lazy style="max-width: 50%" }

#### 第三部分 发货管理

- 点击发货管理下的发货单，可以看到所有的发货单概况，点击还能看到明细

![image-07](/media/img/3n40e6.png){ loading=lazy style="max-width: 50%" }

- 点击发货管理下的拣货单明细，即下图所展示的内容，即所有可以直接拣货的发货单数据，也可以直接扫发货单的二维码。（如扫描的发货单还不能拣货，则扫描的结果为空）

![image-08](/media/img/bb28tq.png){ loading=lazy style="max-width: 50%" }


- 拣货：在拣货单明细中点击要拣货的发货单，输入要拣货的数量，点击确认，返回拣货成功的提示

![image-09](/media/img/m9u4ui.png){ loading=lazy style="max-width: 50%" }

#### 第四部分 手动盘点

- 收货管理确认收一条货以后，就可以进行盘点了（此前需要在web端上进行一下单项盘点）

- 进入库存管理下的手动盘点，确认所有的盘点数量后，点击确认结果，本轮盘点结束。

 ![image-010](/media/img/5usnyg.png){ loading=lazy style="max-width: 50%" }

#### 第五部分 货物查询

- 点击库存管理下的货物查询，扫描货物码，即可出现以下页面

![image-011](/media/img/0iv1we.png){ loading=lazy style="max-width: 50%" }

#### 第六部分 库位列表和库存列表

- 点击库存管理下的库存列表按钮，即可显示所有的库存信息

![image-012](/media/img/h7l40l.png){ loading=lazy style="max-width: 50%" }

- 点击即可进入此货品的库存信息列表，点击可进入移库操作（将A010104库位的货全部移到A010101上去）

![image-013](/media/img/3asmpu.png){ loading=lazy style="max-width: 50%" }

- 移库以后的页面如下所示

![image-014](/media/img/dk2bar.png){ loading=lazy style="max-width: 50%" }

#### 第七部分 手动盘点

- 点击库存管理下的手动盘点按钮，即可显示所有需要盘点的货物明细

- 需要先在WEB端上生成盘点表

![image-015](/media/img/pandian-cn.jpeg){ loading=lazy style="max-width: 50%" }
