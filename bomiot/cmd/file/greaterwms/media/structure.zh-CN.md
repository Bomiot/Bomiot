# 数据结构

## 介绍

- **Bomiot** 支持 Django、FastAPI、Flask，所以 Django 的 ORM 是通用的，并且支持异步。

---

## 用户

```python
from django.contrib.auth import get_user_model

User = get_user_model()  # 获取用户模型
```

- 获取用户模型，然后使用这个 `User` 对用户进行增删改查。

---

## 团队

- 每个用户都必须关联一个团队。
- 团队以组的概念对用户的权限进行管理。
- 当团队的权限发生变化时，用户的权限也同时发生改变。
- 团队不对用户数据进行隔离。

---

## 部门

- 每个用户都必须分配一个部门。
- 部门以数据组的概念对用户数据进行隔离。
- 用户只能看到自己部门的数据。

---

## 数据

- **Bomiot** 认为，前端传给后端是一组标准 JSON 数据，而后端却还需要对 JSON 的每个字段进行逐个编写，这大大降低了工作效率。
- `data` 类的模型只有一个 `JSONField`，Django 的 `JSONField` 已经综合了各种查询读写，非常全面。
- 数据的存取交由 **Bomiot** 的信号进行处理。
- 这样就可以前后端代码一致，比如 `data__value__gte=1`。
- 仅需要确定前端的数据 JSON 字段，即可完成数据管理。
