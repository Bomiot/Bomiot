# 国际化（i18n）

## 文件结构

```
src/i18n/
├── index.js        # i18n 实例
├── zh-CN/index.js  # 中文翻译
└── en-US/index.js  # 英文翻译
```

## 语言状态管理

`stores/language.js` 存储当前语言，持久化到 LocalStorage：

```js
state: { langData: 'en-US' }
```

## 请求头联动

axios 请求拦截器自动携带语言头：

```js
// axios.js
config.headers.language = lang  // 'zh-CN' 或 'en-US'
```

后端根据此头返回对应语言的数据。

## Markdown 文档语言切换

`MDParser` 组件监听语言变化，自动重新加载对应语言的文档：

```js
watch(() => langStore.langData, val => {
  if (val) {
    mdDataChange()  // 请求 md/<docName>.<lang>.md
  }
})
```

后端根据 `docName + lang` 返回如 `axios.zh-CN.md` 或 `axios.en-US.md`。

## 组件中使用

```vue
<script setup>
import { useI18n } from 'vue-i18n'
const { t } = useI18n()
</script>

<template>
  <q-btn :label="t('menuLink.user')" />
</template>
```

## 翻译文件结构

```js
// zh-CN/index.js
export default {
  menuLink: {
    home: '首页',
    user: '用户列表',
  },
  asn: {
    name: 'ASN列表',
    detail: 'ASN明细',
  }
}
```

翻译键采用嵌套对象，使用点号访问：`t('menuLink.home')`、`t('asn.name')`。
