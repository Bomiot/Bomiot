#### APP operation tutorial


#### Part 1  Manager Login

- Enter the administrator information registered on the web end. The default administrator is 3, and the password is also 3. Click the submit button to return a successful login prompt message

![image-01](/media/img/0zanse.png){ loading=lazy style="max-width: 50%" }

![image-02](/media/img/3fx8ja.png){ loading=lazy style="max-width: 50%" }

#### Part 2 Receiving Management

- Click on the ASN under 'inbound', as shown in the following figure

- You can use the QR code of the scanned delivery notice on the web to view the details of this delivery notice

![image-02](/media/img/3fx8ja.png){ loading=lazy style="max-width: 50%" }

![image-03](/media/img/vyv5iu.png){ loading=lazy style="max-width: 50%" }

- Perform the listing operation or scan the QR code of the delivery notice, and the following message appears. If the scanned QR code of the delivery notice still cannot be listed, the scanned data will be empty

![image-04](/media/img/qr1pav.png){ loading=lazy style="max-width: 50%" }

- Click on the arrival notice to be shelved, or scan the item code to be shelved, confirm the name of the storage location to be shelved and the quantity to be shelved, click the confirm button, and this shelving is completed. If you want to shelve again or operate on other arrival notices, please scan the corresponding arrival notice.

![image-05](/media/img/bcnsgn.png){ loading=lazy style="max-width: 50%" }

#### Part 3 Delivery Management

- Click on the DN under Outbound to see an overview of all shipping orders, and click on it to see the details

![image-06](/media/img/tv27ab.png){ loading=lazy style="max-width: 50%" }

- Click on the Picking List under Outbound, as shown in the following figure, which includes all shipment data that can be directly picked, as well as scanning the QR code of the shipment. (If the scanned shipment order cannot be picked yet, the scanned result will be blank)

![image-07](/media/img/l654gu.png){ loading=lazy style="max-width: 50%" }

- Picking: Click on the shipment note to be picked in the picking list details, enter the quantity to be picked, click OK, and return to the successful picking prompt

![image-08](/media/img/hnad2k.png){ loading=lazy style="max-width: 50%" }

#### Part 4 Manual Inventory

- After the receipt management confirms the receipt of a single item, the inventory can be conducted (previously, a single item inventory needs to be conducted on the web)

- Enter the Manual Count under Inventory, confirm all inventory quantities, and click on the confirmation result to end the current round of inventory.

![image-09](/media/img/jl5ia8.png){ loading=lazy style="max-width: 50%" }

#### Part 5: Goods Query

- Click on the goods query under inventory management, scan the goods code, and the following page will appear

![image-10](/media/img/ooihsk.png){ loading=lazy style="max-width: 50%" }

#### Part 6 BinList and Stock List

- Here you can see the inventory information of all the warehouse locations, click to directly access the inventory of the warehouse location, carry out the warehouse transfer operation, or scan the goods to check the storage status of all the go

![image-011](/media/img/faqfia.png){ loading=lazy style="max-width: 50%" }
