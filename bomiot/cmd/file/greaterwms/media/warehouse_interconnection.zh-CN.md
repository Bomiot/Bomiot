## 1.简单介绍

万仓互联是一个基于分享闲置地方供他人使用的概念，您可以把您暂时用不上的一块区域发布到我们的软件上，让其他人可以看到,从而与您联系存放他们的货物，
您可以收取一定的费用。


## 2.创建共享仓库和发布

通过下载局域网使用版或部署开源版本，进入仓库管理，可以看到仓库信息

![image-01](assets/media/img/ck1.png){ loading=lazy }

操作一栏下有几个按钮，1为编辑仓库信息 2为发布仓库信息 3为收回发布出去的仓库

1为编辑仓库
   ~~~shell
    点击编辑按钮，可以出现以下页面
   ~~~
![image-01](assets/media/img/ck2.png){ loading=lazy }

您可以输入要分享的的仓库名称/城市/地址以及您个人的联系方式等信息，再点击右侧的勾状按钮以保存

## 2.发布仓库信息

需要发布时请点击上述页面中的第2个按钮用以发布仓库

![image-01](assets/media/img/ck3.png){ loading=lazy }

点击以后会弹出如下提示

![image-01](assets/media/img/ck4.png){ loading=lazy }

这是让您输入您仓库所拥有的的面积，您也可以输入一段描述信息

## 3.查看已发布的仓库

![image-01](assets/media/img/ck5.png){ loading=lazy }

点击左边的万仓互联按钮就可以看到自己发布的仓库信息，也可以看到其他用户发布的仓库

## 4.收回已发布的仓库

当您基于某种原因，不想分享您的仓库，可以在仓库管理下点击以下按钮用来收回您分享的仓库。

![image-01](assets/media/img/ck6.png){ loading=lazy }

如果您确实不想再分享您的仓库，当提示您成功以后您在万仓互联里就看不到您的仓库了

![image-01](assets/media/img/ck7.png){ loading=lazy }
