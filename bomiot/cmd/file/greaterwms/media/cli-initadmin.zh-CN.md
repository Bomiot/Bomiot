# bomiot initadmin

创建（或重置）项目的超级管理员账号 `admin`。

```bash
bomiot initadmin
```

## 概述

`bomiot initadmin` 确保数据库中存在一个名为 `admin` 的超级管理员：

- **首次执行**：创建 `admin` 账号，初始密码与用户名相同（`admin`），并赋予超级管理员与后台管理权限
- **已存在**：不做任何改动，直接提示可登录
- **账号存在但状态异常**（如被禁用、权限被移除）：重置密码为初始值并恢复全部管理权限

命令必须在**项目根目录**下执行，操作的是当前项目的数据库。

## 使用前提

数据库表已就绪。新项目请先执行：

```bash
bomiot migrate
bomiot initadmin
```

## 账号信息

| 项目 | 值 |
|---|---|
| 用户名 | `admin` |
| 初始密码 | `admin` |
| 邮箱 | `admin@bomiot.com` |
| 权限 | 超级管理员（含后台管理权限） |

> **初始密码仅供临时使用，登录后请立即修改。** 忘记密码时可重新执行 `bomiot initadmin` 将密码重置回初始值（会同时恢复账号激活状态与权限），也可以使用 `bomiot initpwd` 修改密码。

## 典型场景

| 场景 | 操作 |
|---|---|
| 新项目首次登录 | `bomiot migrate` → `bomiot initadmin` → 用 `admin` / `admin` 登录 |
| admin 密码遗忘 | 重新执行 `bomiot initadmin`，密码重置为 `admin` |
| admin 被误禁用或降权 | 重新执行 `bomiot initadmin`，恢复激活状态与全部权限 |
| 生产环境交付 | 执行后**第一时间登录修改密码**，初始密码不可保留在线上 |

## 注意事项

- 该命令直接操作数据库，无需服务处于运行状态
- 初始密码是公开默认值，任何能访问登录页的人都能尝试——**未改密前不要将服务暴露到公网**
- 重复执行安全：账号正常存在时不产生任何变更
- 执行后会打印账号与初始密码提示，注意终端日志中不要长期留存该信息
