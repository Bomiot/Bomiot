# Internationalization (i18n)

## Structure

```
src/i18n/
├── index.js        # i18n instance
├── zh-CN/index.js  # Chinese
└── en-US/index.js  # English
```

## Language State

`stores/language.js` stores current language, persisted:

```js
state: { langData: 'en-US' }
```

## Request Header

axios interceptor adds language header:

```js
config.headers.language = lang  // 'zh-CN' or 'en-US'
```

## Markdown Doc Language

`MDParser` watches language changes and reloads docs:

```js
watch(() => langStore.langData, val => {
  if (val) mdDataChange()  // requests md/<docName>.<lang>.md
})
```

## Usage in Components

```vue
<script setup>
import { useI18n } from 'vue-i18n'
const { t } = useI18n()
</script>

<template>
  <q-btn :label="t('menuLink.user')" />
</template>
```

## Translation File

```js
export default {
  menuLink: { home: 'Home', user: 'User List' },
  asn: { name: 'ASN List', detail: 'ASN Detail' }
}
```

Access with dot notation: `t('menuLink.home')`, `t('asn.name')`.
