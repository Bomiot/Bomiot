#### 说明

!!! info "文档"

    解压后运行目录下的GreaterWMS-start.exe，等待初始化数据库以后,预计耗时10秒以内，会打开登录页面

    建议选择语言为中文，再点击登录按钮

    选择管理员登入

    输入用户名密码为:admin/admin
